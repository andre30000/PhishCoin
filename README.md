What is Phishcoin?
----------------

Phishcoin is a crunchy cryptocurreny which takes its name from a 4-piece improvisational
band from Vermont (and also a term for a sending fraudulent communcations, usually
for a malicious purpose). However, as the headiest jam crypto-coin, we'll leave
the interpretation up to you. Phishcoin is a fork of litecoin and uses 
peer-to-peer technology to operate with no central authority: managing 
transactions and issuing money are carried out collectively by the network. 
Phishcoin Core is the name of open source
software which enables the use of this currency. The dream of this currency is to facilitate (or complicate?)
the purchase of grilled cheeses and ice cold fatties while on lot.
